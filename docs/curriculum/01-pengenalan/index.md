# Modul 01: Pengenalan

**Tingkat:** Pemula

## Tujuan pembelajaran

Setelah modul ini, kamu mampu:

- [ ] Menjelaskan apa itu FastAPI dan kapan memakainya.
- [ ] Menjelaskan peran HTTP dan REST dalam sebuah API.
- [ ] Menyiapkan lingkungan kerja dengan virtual environment.
- [ ] Membuat dan menjalankan aplikasi FastAPI pertama.
- [ ] Membuka dokumentasi interaktif yang dihasilkan otomatis.

## Prasyarat

- Dasar Python (variabel, fungsi, kondisi, perulangan, import).
- Mampu memakai terminal dan editor kode.

!!! tip "Belum siap dengan Python?"
    Materi ini tidak mengajarkan Python dari nol. Sebagai bekal, ada tutorial resmi Python dalam [bahasa Indonesia](https://docs.python.org/id/3/tutorial/index.html) dan [bahasa Inggris](https://docs.python.org/3/tutorial/index.html). Menurut halamannya, tutorial itu ditujukan bagi programmer yang baru mengenal Python, bukan bagi yang baru belajar pemrograman. Jika kamu belum pernah memprogram sama sekali, cari materi pengantar pemrograman dasar terlebih dahulu. Terjemahan Indonesia sebagian teksnya masih berbahasa Inggris.
