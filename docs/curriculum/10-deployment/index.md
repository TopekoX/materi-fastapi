## Tujuan pembelajaran

Setelah modul ini, kamu mampu:

- [ ] Menjalankan aplikasi dengan server untuk produksi.

- [ ] Mengelola variabel environment di produksi.
- [ ] Menambahkan logging.
- [ ] Memeriksa kesiapan rilis dengan checklist.
- [ ] Menyelesaikan tahap 6 proyek praktik: aplikasi siap deploy.
