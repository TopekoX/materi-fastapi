# Modul 02: Dasar Routing

**Tingkat:** Pemula

Modul ini memperdalam cara FastAPI menentukan endpoint mana yang melayani sebuah request. Pembuatan endpoint dan HTTP method sudah dibahas di Modul 01, jadi tidak diulang di sini.

## Tujuan pembelajaran

Setelah modul ini, kamu mampu:

- [ ] Memakai path parameter agar satu endpoint melayani banyak nilai.
- [ ] Memakai query parameter untuk menerima opsi tambahan pada request.
- [ ] Menjelaskan mengapa urutan definisi route berpengaruh.
- [ ] Menjelaskan konsep dasar async/await dalam konteks FastAPI.
