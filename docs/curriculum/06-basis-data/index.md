# Modul 06: Basis Data

**Tingkat:** Menengah

## Tujuan pembelajaran

Setelah modul ini, kamu mampu:

- [ ] Menghubungkan aplikasi FastAPI ke basis data.
- [ ] Membedakan model basis data dan skema API.
- [ ] Menulis operasi CRUD terhadap basis data.
- [ ] Memodelkan relasi antar tabel.
- [ ] Mengelola perubahan skema dengan migrasi.
- [ ] Menyelesaikan tahap 3 proyek praktik: penyimpanan di basis data.
