# Modul 04: Penanganan Error

**Tingkat:** Menengah

## Tujuan pembelajaran

Setelah modul ini, kamu mampu:

- [ ] Memilih status code yang tepat untuk setiap situasi.
- [ ] Mengembalikan error dengan `HTTPException`.
- [ ] Memahami error validasi yang dihasilkan otomatis.
- [ ] Membuat handler error kustom.
- [ ] Menyelesaikan tahap 2 proyek praktik: validasi dan error terstruktur.
