    Proyek: Memecah TugasKu¶

    Tujuan pembelajaran¶

    Setelah mengerjakan halaman ini, kamu mampu:

    • Memecah aplikasi yang sudah berjalan menjadi paket berisi beberapa modul tanpa mengubah perilakunya.
    • Menentukan tanggung jawab tiap berkas: konfigurasi, basis data, error, keamanan, model, dan router.
    • Memindahkan konfigurasi dari kode ke pydantic-settings.
    • Mendaftarkan exception handler dari fungsi terpisah.
    • Membuktikan bahwa perilaku API setelah refaktor sama dengan sebelumnya.

    Prasyarat¶

    • Sudah mengerjakan Proyek Praktik Tahap 4.
    • Sudah membaca Router Modular, Konfigurasi dan Environment, Middleware, dan Lifespan.

    Versi yang diuji

    Kode dan output di halaman ini dijalankan dengan Python 3.14.7, FastAPI 0.162.0, SQLModel 0.0.48, Alembic 1.20.1, PyJWT 2.15.1, pwdlib 0.3.1, dan pydantic-settings 2.16.1 di Windows. Daftar versi lain ada di Versi yang dipakai di materi ini. Versi lain dan sistem operasi lain belum diuji.

    Halaman ini bukan tahap proyek baru

    PRD (§7) tidak menetapkan tahap proyek untuk Modul 08. Halaman ini adalah refaktor dari tahap 4: fitur dan perilaku API sama, hanya strukturnya yang berubah. Kodenya ada di examples/fastapi/proyek/tahap-4-modular/, dan menjadi dasar yang rapi untuk tahap 5 (pengujian) di Modul 09.

    Tentang refaktor ini¶

    Refaktor berarti mengubah struktur kode tanpa mengubah perilakunya. Tahap 4 ditulis di satu main.py sepanjang 322 baris, ditambah models.py. Kini dipecah berdasarkan tanggung jawab:

from pydantic import Field, SecretStr
from pydantic_settings import BaseSettings, SettingsConfigDict


class Settings(BaseSettings):
    # Dibaca dari variabel environment berawalan TUGASKU_ atau dari berkas .env
    model_config = SettingsConfigDict(env_prefix="TUGASKU_", env_file=".env")

    nama_aplikasi: str = "TugasKu API"
    database_url: str = "sqlite:///database.db"
    algoritma: str = "HS256"
    detik_akses: int = Field(default=1800, ge=60)
    origin_diizinkan: list[str] = ["http://localhost:3000"]
    secret_key: SecretStr = Field(min_length=32)  # wajib diisi


@lru_cache
def get_settings() -> Settings:
    return Settings()

    app/errors.py¶

    app/errors.py
    from fastapi import FastAPI, Request
from fastapi.exceptions import RequestValidationError
from fastapi.responses import JSONResponse
from starlette.exceptions import HTTPException as StarletteHTTPException


class TugasTidakDitemukan(Exception):
    def __init__(self, tugas_id: int):
        self.tugas_id = tugas_id


class KategoriTidakDitemukan(Exception):
    def __init__(self, kategori_id: int):
        self.kategori_id = kategori_id


class JudulSudahAda(Exception):
    def __init__(self, judul: str):
        self.judul = judul


class NamaPenggunaSudahAda(Exception):
    def __init__(self, nama: str):
        self.nama = nama


def respons_galat(
    status_code: int, kode: str, pesan: str, rincian: list | None = None, headers: dict | None = None
):
    isi = {"galat": {"kode": kode, "pesan": pesan, "rincian": rincian or []}}
    return JSONResponse(status_code=status_code, content=isi, headers=headers)


def pasang_penangan_error(app: FastAPI) -> None:
    """Mendaftarkan semua exception handler ke aplikasi."""

    @app.exception_handler(TugasTidakDitemukan)
    async def tugas_tidak_ditemukan(request: Request, exc: TugasTidakDitemukan):
        return respons_galat(404, "TUGAS_TIDAK_ADA", f"Tugas dengan id {exc.tugas_id} tidak ditemukan")

    @app.exception_handler(KategoriTidakDitemukan)
    async def kategori_tidak_ditemukan(request: Request, exc: KategoriTidakDitemukan):
        return respons_galat(
            404, "KATEGORI_TIDAK_ADA", f"Kategori dengan id {exc.kategori_id} tidak ditemukan"
        )

    @app.exception_handler(JudulSudahAda)
    async def judul_sudah_ada(request: Request, exc: JudulSudahAda):
        return respons_galat(409, "JUDUL_SUDAH_ADA", f"Judul '{exc.judul}' sudah dipakai")

    @app.exception_handler(NamaPenggunaSudahAda)
    async def nama_pengguna_sudah_ada(request: Request, exc: NamaPenggunaSudahAda):
        return respons_galat(409, "NAMA_PENGGUNA_SUDAH_ADA", f"Nama pengguna '{exc.nama}' sudah dipakai")

    @app.exception_handler(StarletteHTTPException)
    async def http_exception(request: Request, exc: StarletteHTTPException):
        return respons_galat(
            exc.status_code, f"HTTP_{exc.status_code}", str(exc.detail), headers=getattr(exc, "headers", None)
        )

    @app.exception_handler(RequestValidationError)
    async def validasi(request: Request, exc: RequestValidationError):
        rincian = [
            {"field": ".".join(str(b) for b in galat["loc"]), "jenis": galat["type"], "pesan": galat["msg"]}
            for galat in exc.errors()
        ]
        return respons_galat(422, "VALIDASI_GAGAL", "Data yang dikirim tidak valid", rincian)

    @app.exception_handler(Exception)
    async def galat_tak_terduga(request: Request, exc: Exception):
        return respons_galat(500, "GALAT_SERVER", "Terjadi kesalahan pada server")

    app/keamanan.py¶

    app/keamanan.py
    from datetime import datetime, timedelta, timezone
from typing import Annotated

import jwt
from fastapi import Depends, HTTPException
from fastapi.security import OAuth2PasswordBearer
from jwt.exceptions import InvalidTokenError
from pwdlib import PasswordHash
from sqlmodel import select

from .config import get_settings
from .database import SessionDep
from .models import Pengguna

password_hash = PasswordHash.recommended()
HASH_TIRUAN = password_hash.hash("kata-sandi-tiruan")
skema_oauth2 = OAuth2PasswordBearer(tokenUrl="token")


def buat_token(nama_pengguna: str) -> str:
    settings = get_settings()
    isi = {
        "sub": nama_pengguna,
        "exp": datetime.now(timezone.utc) + timedelta(seconds=settings.detik_akses),
    }
    return jwt.encode(isi, settings.secret_key.get_secret_value(), algorithm=settings.algoritma)


def pengguna_saat_ini(token: Annotated[str, Depends(skema_oauth2)], session: SessionDep) -> Pengguna:
    settings = get_settings()
    gagal = HTTPException(
        status_code=401,
        detail="Token tidak valid atau sudah kedaluwarsa",
        headers={"WWW-Authenticate": "Bearer"},
    )
    try:
        isi = jwt.decode(token, settings.secret_key.get_secret_value(), algorithms=[settings.algoritma])
    except InvalidTokenError:
        raise gagal
    nama = isi.get("sub")
    if not nama:
        raise gagal
    pengguna = session.exec(select(Pengguna).where(Pengguna.nama_pengguna == nama)).first()
    if pengguna is None:
        raise gagal
    return pengguna


PenggunaLogin = Annotated[Pengguna, Depends(pengguna_saat_ini)]


def wajib_pengelola(pengguna: PenggunaLogin) -> Pengguna:
    if pengguna.peran != "pengelola":
        raise HTTPException(status_code=403, detail="Hanya untuk pengelola")
    return pengguna


Pengelola = Annotated[Pengguna, Depends(wajib_pengelola)]

    app/routers/auth.py
    from typing import Annotated

from fastapi import APIRouter, Depends, HTTPException, status
from fastapi.security import OAuth2PasswordRequestForm
from sqlmodel import select

from ..database import SessionDep
from ..errors import NamaPenggunaSudahAda
from ..keamanan import HASH_TIRUAN, PenggunaLogin, buat_token, password_hash
from ..models import Pengguna, PenggunaBuat, PenggunaPublik, Token

router = APIRouter(tags=["autentikasi"])


@router.post("/daftar", response_model=PenggunaPublik, status_code=status.HTTP_201_CREATED)
def daftar(data: PenggunaBuat, session: SessionDep):
    ada = session.exec(select(Pengguna).where(Pengguna.nama_pengguna == data.nama_pengguna)).first()
    if ada is not None:
        raise NamaPenggunaSudahAda(data.nama_pengguna)
    pengguna = Pengguna(
        nama_pengguna=data.nama_pengguna,
        hash_kata_sandi=password_hash.hash(data.kata_sandi),
        peran="anggota",
    )
    session.add(pengguna)
    session.commit()
    session.refresh(pengguna)
    return pengguna


@router.post("/token", response_model=Token)
def masuk(form: Annotated[OAuth2PasswordRequestForm, Depends()], session: SessionDep):
    pengguna = session.exec(select(Pengguna).where(Pengguna.nama_pengguna == form.username)).first()
    if pengguna is None:
        password_hash.verify(form.password, HASH_TIRUAN)  # samakan waktu respons
        sah = False
    else:
        sah = password_hash.verify(form.password, pengguna.hash_kata_sandi)
    if not sah:
        raise HTTPException(
            status_code=401,
            detail="Nama pengguna atau kata sandi salah",
            headers={"WWW-Authenticate": "Bearer"},
        )
    return Token(access_token=buat_token(pengguna.nama_pengguna), token_type="bearer")


@router.get("/saya", response_model=PenggunaPublik)
def profil_saya(pengguna: PenggunaLogin):
    return pengguna

    app/routers/tugas.py¶

    app/routers/tugas.py
    from typing import Annotated

from fastapi import APIRouter, Depends, HTTPException, Path, Query, status
from sqlmodel import Session, col, select

from ..database import SessionDep
from ..errors import JudulSudahAda, KategoriTidakDitemukan, TugasTidakDitemukan
from ..keamanan import PenggunaLogin
from ..models import Kategori, Tugas, TugasBuat, TugasDenganKategori, TugasPublik, TugasUbah

router = APIRouter(prefix="/tugas", tags=["tugas"])

IdTugas = Annotated[int, Path(ge=1, title="ID tugas")]


def pastikan_kategori_ada(session: Session, kategori_id: int | None) -> None:
    if kategori_id is not None and session.get(Kategori, kategori_id) is None:
        raise KategoriTidakDitemukan(kategori_id)


def pastikan_judul_unik(session: Session, pemilik_id: int | None, judul: str, abaikan_id: int | None = None) -> None:
    """Judul harus unik per pemilik, tanpa membedakan huruf besar-kecil."""
    pernyataan = select(Tugas).where(Tugas.pemilik_id == pemilik_id, col(Tugas.judul).ilike(judul))
    for tugas in session.exec(pernyataan).all():
        if tugas.id != abaikan_id:
            raise JudulSudahAda(judul)


def tugas_yang_boleh_diakses(tugas_id: IdTugas, pengguna: PenggunaLogin, session: SessionDep) -> Tugas:
    tugas = session.get(Tugas, tugas_id)
    if tugas is None:
        raise TugasTidakDitemukan(tugas_id)
    if tugas.pemilik_id != pengguna.id and pengguna.peran != "pengelola":
        raise HTTPException(status_code=403, detail="Tugas ini bukan milikmu")
    return tugas


TugasDiakses = Annotated[Tugas, Depends(tugas_yang_boleh_diakses)]


@router.post("", response_model=TugasPublik, status_code=status.HTTP_201_CREATED)
def buat_tugas(data: TugasBuat, pengguna: PenggunaLogin, session: SessionDep):
    pastikan_kategori_ada(session, data.kategori_id)
    pastikan_judul_unik(session, pengguna.id, data.judul)
    tugas = Tugas.model_validate(data, update={"pemilik_id": pengguna.id})
    session.add(tugas)
    session.commit()
    session.refresh(tugas)
    return tugas


@router.get("", response_model=list[TugasPublik])
def daftar_tugas(
    pengguna: PenggunaLogin,
    session: SessionDep,
    selesai: bool | None = None,
    kategori_id: int | None = None,
    cari: Annotated[str | None, Query(min_length=2, max_length=50)] = None,
    offset: Annotated[int, Query(ge=0)] = 0,
    limit: Annotated[int, Query(ge=1, le=100)] = 10,
):
    pernyataan = select(Tugas)
    if pengguna.peran != "pengelola":
        pernyataan = pernyataan.where(Tugas.pemilik_id == pengguna.id)
    if selesai is not None:
        pernyataan = pernyataan.where(Tugas.selesai == selesai)
    if kategori_id is not None:
        pernyataan = pernyataan.where(Tugas.kategori_id == kategori_id)
    if cari is not None:
        pernyataan = pernyataan.where(col(Tugas.judul).contains(cari))
    return session.exec(pernyataan.offset(offset).limit(limit)).all()


@router.get("/{tugas_id}", response_model=TugasDenganKategori)
def ambil_tugas(tugas: TugasDiakses):
    return tugas


@router.put("/{tugas_id}", response_model=TugasPublik)
def ganti_tugas(data: TugasBuat, tugas: TugasDiakses, session: SessionDep):
    pastikan_kategori_ada(session, data.kategori_id)
    pastikan_judul_unik(session, tugas.pemilik_id, data.judul, abaikan_id=tugas.id)
    tugas.sqlmodel_update(data.model_dump())
    session.add(tugas)
    session.commit()
    session.refresh(tugas)
    return tugas


@router.patch("/{tugas_id}", response_model=TugasPublik)
def ubah_tugas(data: TugasUbah, tugas: TugasDiakses, session: SessionDep):
    perubahan = data.model_dump(exclude_unset=True)
    for nama in ("judul", "prioritas", "selesai"):
        if nama in perubahan and perubahan[nama] is None:
            raise HTTPException(status_code=400, detail=f"Field '{nama}' tidak boleh null")
    if "judul" in perubahan:
        pastikan_judul_unik(session, tugas.pemilik_id, perubahan["judul"], abaikan_id=tugas.id)
    if "kategori_id" in perubahan:
        pastikan_kategori_ada(session, perubahan["kategori_id"])
    tugas.sqlmodel_update(perubahan)
    session.add(tugas)
    session.commit()
    session.refresh(tugas)
    return tugas


@router.delete("/{tugas_id}", status_code=status.HTTP_204_NO_CONTENT)
def hapus_tugas(tugas: TugasDiakses, session: SessionDep):
    session.delete(tugas)
    session.commit()

    Penjelasan kode¶

    Konfigurasi terpusat¶

    Settings di config.py menggantikan nilai yang sebelumnya tersebar: kunci penandatangan, algoritma, masa berlaku (kini detik_akses), daftar origin, dan alamat basis data. get_settings() memakai @lru_cache sehingga dibaca sekali. Perubahan penting: nama variabel kunci kini TUGASKU_SECRET_KEY (berawalan TUGASKU_), bukan SECRET_KEY seperti di tahap 4. Kunci memakai SecretStr, sehingga nilainya dibaca dengan .get_secret_value() di keamanan.py.

    Basis data di satu tempat¶

    database.py membuat engine dari settings.database_url dan menyediakan SessionDep. Router mengimpornya dari sini, bukan membuat sendiri.

    Error di satu tempat¶

    errors.py berisi kelas exception dan respons_galat. Handler tidak lagi didekorasi dengan @app.exception_handler di tingkat modul (karena app belum ada di sini), tetapi didaftarkan lewat fungsi:

    def pasang_penangan_error(app: FastAPI) -> None:
    @app.exception_handler(TugasTidakDitemukan)
    async def tugas_tidak_ditemukan(request, exc): ...

    main.py memanggil pasang_penangan_error(app). Pola "fungsi yang memasang sesuatu ke aplikasi" membuat modul tidak perlu mengimpor app.

    Keamanan sebagai modul¶

    keamanan.py mengumpulkan hashing, pembuatan dan verifikasi token, serta dependency PenggunaLogin dan Pengelola. Router tinggal mengimpor alias ini. Dependency yang dulu didefinisikan di tengah berkas besar kini mudah ditemukan.

    Router dengan path yang sama¶

    router = APIRouter(prefix="/tugas", tags=["tugas"])

@router.post("", ...)

    Endpoint memakai path "" (kosong) bersama prefix, sehingga URL tetap /tugas dan /kategori, persis seperti di tahap 4. Menulis "/" akan mengubah URL menjadi /tugas/ (lihat pengalihan 307 di Router Modular).

    Perakitan di main.py¶

    main.py hanya merakit: membuat FastAPI, memasang CORSMiddleware dari konfigurasi, mendaftarkan handler error, dan menyertakan tiga router. Ia tidak berisi logika bisnis.

    Alembic dan impor¶

    Di alembic/env.py, impor model berubah dari import models menjadi from app import models, karena modelnya kini ada di paket app. Alembic hanya mengimpor app.models, bukan seluruh aplikasi, sehingga perintah alembic tidak membutuhkan TUGASKU_SECRET_KEY (teruji). Alamat basis data di alembic.ini (sqlite:///database.db) harus sejalan dengan database_url di config.py; keduanya sama di contoh ini, tetapi disimpan di dua tempat.

    buat_pengelola.py¶

    Skrip kini mengimpor engine dan password_hash dari paket app, sehingga memakai konfigurasi yang sama dengan aplikasi. Karena app.database memanggil get_settings() saat diimpor, skrip ini membutuhkan TUGASKU_SECRET_KEY terisi.

    Menjalankan¶

    Dari folder tahap-4-modular/:

    pip install "fastapi[standard]" sqlmodel alembic pyjwt "pwdlib[argon2]" pydantic-settings
$env:TUGASKU_SECRET_KEY = (python -c "import secrets; print(secrets.token_hex(32))")
alembic upgrade head
python buat_pengelola.py rina "sandi-rina-789"
fastapi dev app/main.py

    Server berjalan di http://127.0.0.1:8000. Jika port 8000 dipakai aplikasi lain, tambahkan --port 8001 dan sesuaikan URL di bawah. Kata sandi sandi-rina-789 hanya contoh.

    Keterbatasan

    • Pembuktian ini manual (curl terhadap daftar request tetap), bukan pengujian otomatis. Menggantinya dengan pengujian otomatis adalah topik Modul 09 (tahap 5).
    • Respons 500 tidak diuji ulang pada versi modular.
    • Tampilan Swagger UI, perilaku browser, dan kegagalan saat TUGASKU_SECRET_KEY kosong tidak diuji pada versi modular. Perilaku Settings sudah diuji di Konfigurasi dan Environment.
    • Tidak ada lifespan: tabel dikelola Alembic, jadi tidak ada persiapan saat mulai.

    Kesalahan umum¶

    Kesalahan Akibat
    Memecah sambil menambah fitur Sulit memastikan perilaku tidak berubah. Refaktor dulu, tambah fitur kemudian.
    Menulis path router "/" padahal sebelumnya "" URL berubah ke /tugas/ dan klien lama mendapat pengalihan.
    Lupa memperbarui import models di alembic/env.py Alembic tidak menemukan model. Tidak diuji di sini.
    Memakai nama variabel kunci lama (SECRET_KEY) Konfigurasi baru mencari TUGASKU_SECRET_KEY. Menurut perilaku Settings yang diuji di halaman Konfigurasi, aplikasi menolak mulai bila kunci wajib kosong (tidak diuji ulang pada versi modular).
    Impor melingkar antar modul ImportError. Di sini dihindari dengan aliran satu arah: config → database → models → keamanan → routers → main.
    Menaruh logika bisnis di main.py Kembali menjadi berkas besar. main.py hanya merakit.
    Tidak memeriksa ulang setelah memecah Perilaku bisa berubah tanpa disadari. Jalankan kembali daftar request.

    Latihan¶

    1. Dasar. Berkas mana yang kamu ubah bila masa berlaku token diganti menjadi 10 menit?
    2. Prediksi. Mengapa alembic upgrade head tidak butuh TUGASKU_SECRET_KEY, sedangkan buat_pengelola.py butuh?
    3. Praktik. Tambahkan router pengguna dengan GET /pengguna/saya. Berkas apa yang dibuat dan diubah?
    4. Analisis. Mengapa pasang_penangan_error(app) berupa fungsi, bukan dekorator di tingkat modul errors.py?
    Kunci jawaban

    Jawaban 2 mengacu pada hasil uji di atas. Jawaban 1, 3, dan 4 adalah penalaran dari struktur; jawaban 3 tidak dijalankan.

    1. Tidak ada berkas kode yang diubah: cukup TUGASKU_DETIK_AKSES=600 di environment (atau .env), karena nilainya dibaca dari Settings. Syaratnya detik_akses minimal 60.
    2. Alembic hanya mengimpor app.models, yang tidak memanggil get_settings(). buat_pengelola.py mengimpor app.database, yang memanggil get_settings() saat diimpor dan butuh kunci.
    3. Buat app/routers/pengguna.py dengan APIRouter(prefix="/pengguna", ...) dan endpoint GET /saya memakai PenggunaLogin, lalu tambahkan from .routers import pengguna dan app.include_router(pengguna.router) di main.py.
    4. Dekorator @app.exception_handler(...) butuh objek app, yang dibuat di main.py. Dengan fungsi yang menerima app, errors.py tidak perlu mengimpor main.py (yang akan membuat impor melingkar).

    Ringkasan¶

    • Refaktor mengubah struktur tanpa mengubah perilaku; bukti perilaku sama adalah menjalankan kembali daftar request yang sama.
    • Pecah berdasarkan tanggung jawab: konfigurasi, basis data, error, keamanan, model, router, dan main.py yang hanya merakit.
    • Konfigurasi dipindah ke pydantic-settings; kuncinya kini TUGASKU_SECRET_KEY.
    • Handler error dipasang lewat fungsi agar tidak ada impor melingkar.
    • Path router kosong ("") menjaga URL tetap sama dengan sebelum dipecah.
    • Alembic mengimpor model dari paket app dan tidak membutuhkan konfigurasi rahasia.
